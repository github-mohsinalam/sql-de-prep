## Problem naming convention
`<id>-<short-slug>.sql`, e.g. `176-second-highest-salary.sql`

Each solution file should start with a header comment:
```sql
-- Source: LeetCode 176
-- Difficulty: Medium
-- Pattern: self-join / correlated subquery for Nth highest
-- Link: https://leetcode.com/problems/second-highest-salary/
```
